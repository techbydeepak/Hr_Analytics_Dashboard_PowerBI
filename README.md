# HR Analytics Dashboard 📊

## Overview

The **HR Analytics Dashboard** is a Power BI project developed to analyze employee attrition and workforce trends. This dashboard provides insights into employee demographics, salary distribution, education background, job roles, and employee attrition patterns.

The project helps in understanding workforce behavior and identifying key areas affecting employee retention through interactive visualizations.

---

## Objectives

* Analyze employee attrition trends
* Understand salary and age-based attrition
* Identify job roles with high employee turnover
* Explore workforce insights using data visualization

---

## Tools & Technologies Used

* **Power BI** – Dashboard Development
* **CSV Dataset** – Data Source
* **Power Query** – Data Cleaning & Transformation
* **DAX** – KPI Calculations

---

## Dashboard Features

### Key Metrics

* **Overall Employees:** 1470
* **Attrition Count:** 237
* **Attrition Rate:** 16.1%
* **Average Age:** 37
* **Average Salary:** 6.5K
* **Average Years at Company:** 7.0

### Key Insights

* Highest attrition is found in the **26–35 age group**
* Most attrition occurs in the **salary slab below 5K**
* **Laboratory Technician** and **Sales Executive** roles show high attrition
* Employees from **Life Sciences** and **Medical** backgrounds contribute more to attrition
